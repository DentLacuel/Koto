
### DevLog 2: 10-Oct-2026


# Choix techniques et technologique:

Pour le développement du projet Koto, j'ai décidé d'utiliser des technologies web courantes afin de construire une application fonctionnelle et de bien comprendre les bases du développment web.

# Frontend : HTML, CSS, JavaScript

J'ai décidé d'aller avec HTML, CSS et Vanilla JavaScript comme fondation du frontend de Koto.

HTML pour structurer les pages de l'application, les formulaires et les annonces.

CSS pour définir le style visuel de l'application, la mise en page et l'adaptation au différent tailles d'écran.

JavaScript (Vanilla) : sera utilisé pour qjouter l'intéractivité, programmer les fonctionnalités et communiquer avec le Backend.


- Je n'ai pas d'éxperience approndie avec ces technologies, j'ai donc choisi ded les apprendre en développant directement Koto plûtot que de commencer avec un framework frontend. Je veux toucher à tout moi-même!

Cette approche me permettra de bien comprendre les fondement du  développement web avant d'envisager des frameworks avancés.


# Backend : Node.js + Express.js

Node.js pour exécuter JavaScript côté serveur, tandis que Express.js simplifiera la création du serveur web et des routes de l'application.

Aussi, ces technologies permetterons notamment :
- Reception et traitement des requêtes envoyées par le frontend
- Gestion des comptes utilisateurs et annonces
- Communication avec la base de données
- Mise en place progressive des fonctionnalités de Koto.

# Base de données : PostgreSQL

J'ai choisi PostgreSQL car c'est un système qui permettra de gérer des relations entre plusieurs types de données, il sera utilisé pour:

- Enregistrer les comptes utilisateurs et leur informations nécéssaires.

- Stocker les annonces, descriptions, prix, localisation...

- Effectuer des recherches et filtrer les annonces selon différents critères.

Le choix de PostgreSQL me permettra d'apprendre SQL et principes de conception d'une base de donnée relationnelle pour mon projet.
