### User Stories:

# October 07 2026.


# Compte utilisateur

1. Création de compte

Entant que visiteur, je veux créer un compte avec mon nom, mon adresse courriel et un mot de passe afin de pouvoir utiliser les fonctionnalités de la platforme.

2. Connexion

Entant qu'utilisateur, je veux me connecter à mon compte afin d'accéder à mes fonctionnalités personnelles.

3. Déconnexion

Entant qu'utilisateur avec une session ouverte, je veux me déconnecter afin de protégerl'accès à mon compte.

# Les annonces

4. Créer une annonce

Entant qu'utilisateur connecté, je veux créer une annonce afin de vendre ou donner un objet dont je n'ai plus besoin.

L'annonce contiendra :

- Un titre
- Une desciption de l'article
- Au moins une photo
- Localisation
- La catégorie
- Mots-clés/tags
- Type : vente ou don

5. Consulter une annonce

Entant qu'utilisateur, je veux consulter les détails d'une annonce afin de voir si l'objet m'interesse ou pas.

6. Modifier/Supprimer une annonce

Entant que propriétaire de l'annonce je veux voir mes annonces, les modifier afin de les garder à jour et je veux les supprimer quand l'objet n'est plus disponible afin qu'elles ne soient plus visibles.

7. Recherche d'articles 

Entant qu'utilisateur, je veux rechercher des annonces à l'aide de mots clés afin de pouvoir trouver rapidement les objets que je cherche.
